# Vehicle Identification System

## Overview

The Vehicle Identification System is a comprehensive JavaFX desktop application designed to help police, vehicle owners, workshops, and insurance providers manage vehicle-related information efficiently. The system provides real-time vehicle tracking, stolen vehicle reporting, document expiry detection, vehicle movement reconstruction, and insurance management.

## Features

### Police Module
- Search vehicles by registration number
- Report stolen vehicles with automatic BOLO alerts
- Add and manage traffic violations
- Issue and track warrants
- Real-time vehicle tracking with geofencing
- Vehicle movement reconstruction using ANPR and traffic camera data
- Expired document detection with automatic fine generation

### Customer Module
- Manage personal profile and vehicles
- Submit queries to workshops
- File complaints and submit reviews
- Digital wallet for payments
- Service history visualization
- Document expiry calendar

### Workshop Module
- Manage workshop profile and mechanics
- Service record management
- Parts inventory tracking
- Digital vehicle inspection
- QR code check-in for vehicles
- Revenue analytics and reporting

### Insurance Module
- Manage insurance policies
- Process claims with approval workflow
- Insurance verification
- Provider comparison
- No-claim bonus calculation

### Admin Module
- User management with role-based access control
- System audit logs
- Database backup and restore
- Bulk data import/export
- System health monitoring
- Scheduled report generation
